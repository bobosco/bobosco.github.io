资源下载页使用说明 / How to use the resources page
====================================================

中文：
1. 把要分享的文件复制到 public/files/ 目录（可以建子目录）。
2. 打开 src/data/resources.ts，仿照现有条目添加一条记录：
   file 写文件名，name 和 description 分别写中英文名称与简介。
3. 保存后网站会自动更新，访问者点击「下载」即可获取文件。

English:
1. Copy the file you want to share into the public/files/ directory
   (subdirectories are fine).
2. Open src/data/resources.ts and add an entry following the existing one:
   set `file` to the file name, and fill in `name` / `description`
   in both Chinese and English.
3. Save and the site updates automatically — visitors can then download it.
